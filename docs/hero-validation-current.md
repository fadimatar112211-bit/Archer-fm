# Hero validation gate

CI runs `flutter analyze --no-fatal-infos` and `flutter test`.

Ranger, Flame and Shadow have 64 state/direction clips and atlases each. Storm's static GLB is not a rigged eight-direction runtime asset and remains blocked until its rigged source and rendered atlas set are committed.

The combat viewer currently provides a deterministic training-target sandbox, not production arena collision, enemy AI, multiplayer or match progression.

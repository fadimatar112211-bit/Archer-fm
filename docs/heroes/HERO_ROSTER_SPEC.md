# أبطال Archer FM الأربعة — عقد الإنتاج والتكامل

آخر تحديث: 2026-11-15

هذا المستند يصف الجيل الحالي من أبطال اللعبة: أربعة أبطال مبنيين إجرائياً في
Blender، ولكل بطل 8 حركات × 8 اتجاهات، مع تكامل حقيقي داخل تطبيق Flutter.

## 1. الأبطال

| المعرّف | الاسم العربي | الدور | السلاح | المهارة |
| --- | --- | --- | --- | --- |
| `ranger` | الرامي المتوازن | بعيد المدى · توازن | قوس الطاقة الخضراء | وابل السهام |
| `flame` | فارس اللهب | قريب المدى · إلحاق ضرر | سيف اللهب العظيم | انفجار الجحيم |
| `shadow` | ظل الليل | قريب المدى · اغتيال | خنجران توأمان | اندفاع الظل |
| `storm` | حامل العاصفة | متوسط المدى · تحكم | رمح الصاعقة | ضربة الرعد |

المرجع البصري للرامي هو `assets/heroes/ranger/ranger_reference_crop.png`، وهو
يحكم على أي وصف نصي عند التعارض. أما هوية اللهب والظل والعاصفة فمأخوذة من وصف
المستخدم ولوحات الألوان القديمة:

- اللهب: `#FF8A24` / `#A93620` — أحمر وذهبي ونار.
- الظل: `#4C2678` / `#28133F` — بنفسجي داكن وقناع.
- العاصفة: `#15516B` / `#E3FFFF` — أزرق وذهبي وبرق.

## 2. ما تتشاركه الأبطال

كل الأبطال يُبنون من نفس الملف `tools/blender/build_ranger_source.py` ونفس
الهيكل العظمي ونفس شبكة التظليل والشبكة الزمنية:

- نفس نسب الجسم chibi، نفس الرأس واليدين والحذاء، نفس الكاميرا الإيزومترية.
- نفس الـ 30 عظمة، ونفس أسماء العظام، ونفس ترتيب الأب/الابن.
- نفس تظليل الخلايا: Diffuse ← ShaderToRGB ← ColorRamp ← Emission مع حافة مضيئة.
- نفس توقيت الحركات وعدد الإطارات ونقاط الارتكاز.
- نفس أسماء الأحداث في البيان، لذلك يعمل مشغّل الحركة نفسه مع الجميع.

الاختلاف بين الأبطال يأتي من ملف `tools/blender/hero_profiles.py`:

- لوحة الألوان والمواد.
- الشعر أو القلنسوة أو الإكليل.
- شكل العباءة وطولها وحافتها.
- قطع الدرع الإضافية (كتف، صدر، حزام، جراب).
- شبكة السلاح وموضعه في اليد.
- تأثيرات الطاقة الخاصة.
- حركتا الهجوم والمهارة.

## 3. الحركات والاتجاهات

كل بطل يملك الحركات التالية:

`idle, walk, run, attack, skill, dodge, hit, death`

وكل حركة تُرسم في ثمانية اتجاهات:

`s, sw, w, nw, n, ne, e, se`

مجموع الإطارات لكل بطل: 62 وضعية × 8 اتجاهات = 496 إطاراً، ثم 64 أطلساً.

## 4. أحداث اللعب

الأحداث جزء من بيان الحركة وتُستهلك في التطبيق لتشغيل التأثيرات:

| البطل | الحركة | الأحداث |
| --- | --- | --- |
| الجميع | `dodge` | `dodge_start` @5، `dodge_end` @17 |
| الجميع | `hit` | `hit_react` @5 |
| الجميع | `death` | `death_complete` @29 |
| `ranger` | `attack` | `bow_draw` @9، `projectile_release` @13 |
| `ranger` | `skill` | `volley_charge` @9، `volley_release` @17 |
| `flame` | `attack` | `weapon_windup` @5، `melee_impact` @13 |
| `flame` | `skill` | `inferno_charge` @9، `inferno_burst` @17 |
| `shadow` | `attack` | `weapon_windup` @5، `melee_impact` @13 |
| `shadow` | `skill` | `shadow_charge` @9، `shadow_burst` @17 |
| `storm` | `attack` | `weapon_windup` @5، `melee_impact` @13 |
| `storm` | `skill` | `storm_charge` @9، `thunder_strike` @17 |

## 5. مسارات الأصول

```
assets/heroes/<hero>/
  renders/
    <hero>_manifest.json
    <state>/<direction>/<frame>.png
    atlases/<state>_<direction>.png
    atlases/<state>_<direction>.json
  source/
    <hero>_source.blend
```

نقطة الارتكاز في كل إطار: `{ "x": 0.5, "y": 0.86 }`، وحجم الإطار 192×192.
الأطلس بعمودين وأربعة صفوف افتراضياً، مع حشوة بكسل واحدة بين الإطارات.

## 6. خط الإنتاج في CI

سير العمل `Ranger Blender Asset Pipeline` ثابت المسارات ولا يمكن تعديله، لذلك
يُختار البطل عبر ملف `tools/blender/active_hero.txt` (سطر واحد). يبني التشغيل
بطلًا واحداً، ثم:

1. يبني ملف `.blend` القابل للتعديل.
2. يتحقق من المشهد والهيكل والمواد والحركات.
3. يرسم 496 إطاراً.
4. يرفض الإطارات الفارغة أو المقصوصة أو التي تنتمي لبطل سابق.
5. يحزم 64 أطلساً ويتحقق من كل بكسل.
6. يتحقق من بيان الأصول النهائي.

البطل غير الرامي يُنسخ إلى
`assets/heroes/ranger/renders/_bundle/<hero>/` داخل مخرجات CI (مجلد مهمَل في
git)، ثم يُنقل إلى مساره النهائي عند الدمج. السبب أن سير العمل يرفع مسار
الرامي الثابت فقط.

## 7. التكامل في Flutter

- `lib/hero/hero_catalog.dart`: تعريف الأبطال الأربعة وألوانهم وأيقوناتهم
  وأسمائهم وأسلحتهم ومهاراتهم.
- `lib/hero/hero_assets.dart`: `BundleHeroAssetLoader` يقرأ بيان البطل وأطالسه
  من مجلد البطل، و`HeroLoaderFactory` يبني محمّلاً لكل بطل.
- `lib/hero/hero_viewer_screen.dart`: شاشة العرض مع اختيار البطل والحركة
  والاتجاه والسرعة، وسجل الأحداث.
- `lib/hero/hero_stage.dart`: خلفية المسرح والأرضية والظل والتأثيرات، وتتلوّن
  حسب هوية البطل.
- `lib/hero/sprite_player.dart`: مشغّل الإطارات والأحداث المشترك.

عند اختيار بطل آخر تُحرَّر أطالس البطل السابق ويُبنى محمّل جديد. إذا لم تكن
أصول البطل مضمّنة بعد، تظهر رسالة عربية واضحة بدل الانهيار.

### ربط الأحداث بالتأثيرات

| الحدث | التأثير |
| --- | --- |
| `projectile_release` | حلقة طاقة سريعة |
| `volley_release` | ثلاث حلقات متتابعة |
| `bow_draw` / `volley_charge` / `weapon_windup` / `*_charge` | هالة تجميع نابضة |
| `melee_impact` | وميض ضربة قوسي |
| `inferno_burst` / `shadow_burst` | حلقات انفجار بلون البطل |
| `thunder_strike` | صاعقة متعرجة حتى الأرض |
| `hit_react` | وميض أحمر |
| `dodge_start` / `dodge_end` | خطوط اندفاع |

## 8. إضافة بطل خامس

1. أضف ملف تعريف في `hero_profiles.py` (لوحة، عباءة، سلاح، تأثيرات، هجوم،
   مهارة).
2. أضف تعريفاً في `hero_catalog.dart` بنفس المعرّف.
3. اكتب المعرّف في `active_hero.txt` وشغّل خط الإنتاج.
4. انقل `_bundle/<hero>/renders` إلى `assets/heroes/<hero>/renders` وأعد تسمية
   البيان إلى `<hero>_manifest.json`.
5. أضف مسار الأصول إلى `pubspec.yaml`.
